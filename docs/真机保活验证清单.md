# 真机保活验证清单（小米 / OPPO / 华为等）

> 为什么必须做这一步：保活第二层（`onTaskRemoved` + 看门狗 + 电池优化白名单）是**专门为厂商 ROM 写的**，
> 但只在模拟器（Android 12 / 原生）上验证过。**厂商 ROM 会不会杀、白名单起不起作用，
> 只有真机能给出答案**。模拟器通过 ≠ 真机通过。

APK：`out\TraeWork2API-0.2.0-debug.apk`（约 1.5 MB，debug 签名）
（用工程根的 `.\build-apk.ps1` 生成，文件名里的版本号取自 `app\build.gradle.kts` 的 `versionName`。）

---

## 准备

1. 把 APK 传到手机安装（允许"安装未知来源应用"）。
2. 手机和电脑连同一个 WiFi（或直接用手机上的客户端，见下）。
3. 电脑上装好 adb 并连上手机：`adb devices` 能看到设备。

> **更省事的替代方案**：不用电脑，直接在手机上装 **Chatbox** 之类的 OpenAI 兼容客户端，
> base URL 填 `http://127.0.0.1:8788`。所有验证都能在手机上完成。

## 一、先做保活设置（最关键，别跳过）

打开 App → **概览** → 点「**启动服务**」→ 点「**检查保活设置**」。

体检面板会逐项告诉你缺什么。**必须全部变成 ✓**，其中：

| 项目 | 怎么开 |
|---|---|
| **电池优化白名单** | 点面板里的「去开白名单」→ 允许。**这是最管用的一项** |
| 通知权限 | Android 13+ 会弹窗，选"允许" |
| 精确闹钟 | 面板里的「去开精确闹钟」，或 设置 → 应用 → 特殊权限 → 闹钟和提醒 |
| 自启动 / 后台运行 | **系统查不到，要自己找**（见下表） |
| 省电策略 | 设为「无限制 / 不优化」 |

**各品牌位置（系统查不到，只能手动找）**：

- **小米 / Redmi（MIUI / HyperOS）**：设置 → 应用设置 → 应用管理 → TraeWork2API →
  **自启动**打开；**省电策略** → 选「无限制」；**权限管理 → 后台弹出界面** 允许
- **OPPO / 一加 / realme（ColorOS）**：设置 → 电池 → 应用耗电管理 → TraeWork2API →
  允许**完全后台行为**、允许**自启动**、关闭**智能省电**
- **华为 / 荣耀（EMUI / MagicOS）**：设置 → 应用 → 应用启动管理 → 关掉"自动管理"，
  把**自启动 / 关联启动 / 后台活动**三个都打开
- **vivo（OriginOS）**：设置 → 电池 → 后台耗电管理 → 允许后台高耗电；
  i 管家 → 自启动 → 允许

## 二、逐项验证（每条都要看到预期结果）

| # | 操作 | 预期结果 |
|---|---|---|
| 1 | 点「启动服务」 | 状态变「服务运行中」，**通知栏出现「TraeWork2API 网关」** |
| 2 | 客户端发一条消息 | 正常回复 |
| 3 | **按 Home 回桌面**，再发一条 | 仍正常回复 |
| 4 | **从最近任务划掉 App** ⚠️ | 划掉后**等 10 秒**，再发一条 → **仍正常回复**。<br>（模拟器上这条没测到，**这次就是来验它的**） |
| 5 | **锁屏放 10 分钟**，再发一条 | 仍正常回复 |
| 6 | 手机**重启** | 服务是**关闭**的（符合设计：不开机自启）。重新打开 App 点启动即可 |
| 7 | 点「停止服务」 | 端口关闭、**通知消失**；等 15 分钟以上**不能自己又跑起来** |

### 第 4 条是重点
如果划掉后**不能**回复了 → 说明厂商把前台服务连带杀了，且 `onTaskRemoved` 的拉回被拦。
**请把当时的日志抓给我**（见下），我据此调整。

### 第 7 条也别漏
"点了停止、15 分钟后自己又开了"是**看门狗没取消干净**的症状。这是我最担心的回归点。

## 三、出问题时抓日志（重要）

连着电脑，复现问题时执行：

```bash
adb logcat -c            # 先清空
# ……在这里复现问题……
adb logcat -d -s GatewayService:* Gateway:* LocalFakeServer:* > 保活日志.txt
adb logcat -b crash -d > 崩溃日志.txt
adb shell dumpsys alarm | grep -A6 traework2api > 闹钟.txt
adb shell dumpsys deviceidle whitelist | grep traework2api > 白名单.txt
```

**重点看这几行**（有就是走了对应路径）：

| 日志 | 含义 |
|---|---|
| `任务被划掉，正在拉回服务` | 划掉后触发了拉回 ✅ |
| `后台拉起被拦，退化为精确闹钟` | 被 Android 12+ 限制拦住，已用闹钟兜底（**不算失败**） |
| `任务被划掉，但用户已停止服务 → 不拉起` | 你主动停过，正确地没拉回 ✅ |
| `唤醒锁已持有（冻结豁免生效）` | 唤醒锁正常 |
| `看门狗已取消` | 停止时看门狗撤掉了 ✅ |
| `精确闹钟未授权，看门狗 降级为非精确` | ⚠️ **需要去开精确闹钟**，否则被杀后可能很久才恢复 |
