## 3. 实现约束（做第 2 步时看）

### 3.1 `ModelsRepo` 改法（已给最小形状，别过度设计）

现状是 `private val current: JSONArray = buildStatic()` —— **不可变**。改成：

```kotlin
@Volatile private var dynamic: JSONArray? = null
fun current(): JSONArray = dynamic ?: static          // 拉不到就回静态表
fun applyFetched(arr: JSONArray) { if (arr.length() > 0) dynamic = arr }
```

**硬约束（违反就是 bug）**：
1. **静态表必须保留做兜底**。未登录 / 断网 / 上游 500 时，`current()` 必须回落到静态表。
   `LocalFakeServer` 的 `/v1/models` 与模型 Tab 都读它 ——
   **返回空数组会让所有客户端看不到任何模型**（比少一个新模型严重得多）。
2. **空表 / 解析失败一律拒绝覆盖**（`arr.length() > 0` 那道闸）。
   别"刷一次失败把好好的清单清空了"。
3. **`DEFAULT_MODE` 绝不跟着动态表变**。现在它是 `DeepSeek-V4-Flash`
   （用户明确要求"别默认用贵的"，见 `TraeUpstream.kt:42-49`）。
   动态表里很可能有更贵/更新的模型排在前面，**顺位成默认会烧用户积分**。
4. **第一版不做持久化**：重启回静态表。用户要的是"刷最新"，不是"离线缓存"。
   （若用户以后要缓存，再加 prefs，先问。）

### 3.2 按钮与刷新行为

- 位置：模型页搜索框那行（`MainActivity.kt:580` `modelsPage()`），
  或者在搜索框下方 —— 用现成的 `action("刷新模型", full = true)` / `linkAction`。
- 🔴 **必须"原地更新"，不能用 `render(currentPage)` / `redraw()`**：
  那会 `removeAllViews()` 重建内容区 → **搜索框内容与滚动位置全丢**。
  这个坑项目里**已经踩过**（`.workbuddy\memory\MEMORY.md` 的"积分刷新"那条）：
  做法是**把卡片容器的句柄留给回调**，回调里 `removeAllViews()` 再重塞卡片。
- ⚠️ **重塞后必须同步 TextWatcher 的 `cards` map**（`MainActivity.kt:592-601`，
  `cards.forEach` 在 598 行），否则刷新后**搜索过滤会作用在已失效的旧 View 上**（表现：搜索框像坏了）。
- **加载态**：「刷新中…」+ 按钮置灰禁用（照抄记录页/积分刷新现有写法，别新造轮子）。
- **失败态**：toast 说人话，例如「拉取失败：<原因>，仍显示内置清单」。**禁止静默失败。**
- **成功但无新增**：也提示「已是最新（N 个模型）」，让用户确信按钮真的起作用了。
- 线程：网络请求**必须在后台线程**，回到主线程再改 UI（项目无协程库，用 `Thread{}` + `runOnUiThread`）。

### 3.3 零新依赖 / 零布局 XML（项目铁律）

### 4.3 测试方法坑（别重蹈）

- `adb` 在 `D:\Android\sdk\platform-tools\adb.exe`，**必须 `-s 127.0.0.1:5555`**（否则报多设备）
- **`adb forward` 在本环境不可用**；用 `adb shell curl` + **body 先 `adb push` 再 `--data-binary @文件`**
  （内联 `-d 'json'` 会被 shell 转义破坏）
- ⚠️ **PowerShell 5.1 会把含中文/引号的复杂命令搞坏**（`The string is missing the terminator`）。
  把脚本写成 **UTF-8 文件** push 上去再 `sh` 执行，别硬拼内联字符串
- ⚠️ **中文数据**：PowerShell 管道传中文会静默变 `?`。**先 write 成 UTF-8 文件再 push**
- ⚠️ **别用 PowerShell/sed 改 `.kt` 源码**：会把 UTF-8 中文注释变乱码（项目真踩过，交接文档 §5.8）
- UI 自动化：**先 `uiautomator dump` 再按文案定位**，坐标随风格变，别用固定坐标
- 模拟器锁死横屏，真竖屏测不了
