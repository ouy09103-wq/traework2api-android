### 做了什么

1. **新增 `app/src/main/java/com/example/traework2api/AppStyle.kt`**
   - `Style` 数据类：中文名 + 圆角三档 + 间距节奏 + 亮/暗两份色表（19 个语义键）。
   - 4 套风格：靛蓝（默认，沿用原 wb_* 色板）/ 石墨（方正冷灰紧凑）/ 苔绿（大圆角舒展）/

### 关键踩坑（都已修，别再踩）

- **`R.color.*` 换不了风格**：编译期常量，只能区分 values / values-night。
- **`recreate()` 后状态其实是好的，但 `loadAndRefreshToken()` 随后又 `render(currentPage)`
  一次，把停在二级页的用户踢回 Tab 页** → 用 `redraw()` 解决。
- 自动化点击的坑（见 `docs/UI现状清单.md` §7）：坐标随风格变（CARD_PAD/GAP 不同，差值上百 px）、
  `recreate()` 后 2 秒内点击会被丢、`MSYS_NO_PATHCONV=1` 时 adb 的文件路径要写 `D:/...`。
- 模拟器被锁死横屏，真竖屏测不了；用 `wm size 2340x1080` + `density 420` 得到 411dp 宽的
  app 窗口代替（`wm size 1080x2340` 反而得到 891dp 宽）。

## 第三轮：桌面图标改成自适应图标（同日）

用户问"桌面图标该改成什么样"，我画了 4 个候选（端口环 / 双向箭头 / 闸门 / 钥匙）让他挑，
他选了 **双向箭头 + 靛蓝底**。

### 改动

- 新增 `mipmap-anydpi-v26/ic_launcher.xml`（自适应图标：background + foreground + monochrome）
- 新增 `drawable/ic_launcher_background.xml`（满幅 `#4F46E5`）
- 新增 `drawable/ic_launcher_foreground.xml`（白色 ⇄，图形宽 54/108，落在中间 72×72 安全区内）
- 新增 `mipmap-anydpi/ic_launcher.xml`（API 24–25 回落，满幅方形、图形 60/108）
- 删除 `drawable/ic_launcher.xml`（旧的「W」标记）
- manifest：`android:icon` 由 `@drawable/ic_launcher` 改为 `@mipmap/ic_launcher`

### 关键知识

- **原图标是 108dp 满幅方块且没做自适应** → Android 8+ 当 legacy 图标塞进遮罩再缩小一圈，
  看起来比别人小一截。改自适应后系统按启动器形状（圆/方圆形）自己遮罩。
- **前景必须落在中间 72×72**（圆形遮罩约 66）；直接照搬"满幅图标"的图形尺寸会显得过大，
  要按 72 而不是 108 来算比例。
- **桌面图标不能跟 App 内风格切**（要多个 activity-alias + setComponentEnabledSetting），
  固定靛蓝当招牌色。
- 验证用 `aapt2 dump badging <apk> | grep icon` → 确认解析到 `mipmap-anydpi-v26/ic_launcher.xml`；
  再看系统「应用信息」页（`am start -a android.settings.APPLICATION_DETAILS_SETTINGS -d package:<pkg>`）
  —— 那是 Android 自己按 PackageManager 渲染的图标，比在桌面上找图标可靠
  （MuMu 的桌面是它自己的精简桌面，根本不显示本应用）。

   （chip 与按钮同时「启动中…/停止中…」+ 按钮置灰禁用）。

### 踩到的真问题（重要）

- **`render()` 会重建内容区 → 滚动位置弹回页首**。给积分刷新加加载态后，
  实测「积分与用量」卡在视口外，加载态一次都没被看见。
- 先试过给 `redraw()` 加"记住 scrollY、画完滚回去"——**不可靠**：新 ScrollView 内容高度
  还没量完，`scrollTo` 被夹回 0；在 `post` 里注册 `OnGlobalLayoutListener` 也稳定不了。
  **最终改为"原地更新"**：`accountPage` 把"怎么把数据刷进那几个控件"登记到 `quotaApply`，
  刷新前后各调一次，页面不重建 → 滚动位置不丢、也不闪。
  配套把 `metric(label, value)` 改成 `metricOf(label, valueView)`（值控件由调用方持有）。
- 结论（已写进 `docs/UI现状清单.md` §3.5）：**要保住滚动位置，就别重建页面。**
