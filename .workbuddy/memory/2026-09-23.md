**踩到的坑（下次直接用）**
1. **chip 在竖直 LinearLayout 里会被拉成整条横幅**（实测 bounds 横跨整屏）。
   根因未完全定位，但显式 `layoutParams = lp(-2,-2)` 可解；`row` 内本来正常。
2. **adb 在 Git Bash 下必须带 `MSYS_NO_PATHCONV=1`**，否则 `/sdcard/x.png` 被转成 Windows 路径。
3. 本机 Bash 工具对 **shell 变量形式（`A=...; $A ...`）会报沙箱错误**，
   改用完整路径重复写即可（`MSYS_NO_PATHCONV=1 /d/Android/sdk/platform-tools/adb.exe ...`）。
4. 构建输出用 `Select-String` 过滤时可能返回空，用 `$LASTEXITCODE` 或检查 APK 时间戳判断成功。
